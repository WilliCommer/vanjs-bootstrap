VanJs Bootstrap Component Demo

Introduction

This document shows how easy it is to build a UI with VanJs and Bootstrap. Using simple examples, this document demonstrates how the library is used. The integrated form generator allows you to create a basic template for your forms.

Why to use VanJs

VanJS (Vanilla JavaScript) is used primarily because it is the world's smallest reactive UI framework, packing modern framework features into an ultra-lightweight, 1.0kB bundle. It bridges the gap between pure vanilla JavaScript and heavy frameworks like React, allowing you to build reactive web apps instantly without complex tooling.

Why to use Bootstrap

Bootstrap is used because it dramatically speeds up web development by providing a ready-made library of responsive, mobile-first UI components. Instead of writing thousands of lines of custom CSS and media queries from scratch, developers can rapidly build complete, functional layouts simply by dropping predefined classes onto HTML elements.

Why to use vanjs-bootstrap

Using vanjs-bootstrap is a great choice if you want to build highly responsive, modern UI applications with Bootstrap while keeping your JavaScript bundle size as small as humanly possible. Developed as a community add-on, vanjs-bootstrap serves as a bridge between VanJS (the world's smallest reactive UI framework at just 1.0kB) and the popular Bootstrap CSS utility library.

Button

export function Button ({bsSize, class, color='secondary', outline, dropdown, ...props}, children)

Implements a Bootstrap button

Let’s start with the Button component to understand the underlying principle of this component library. The Button is a function structured like a VanJS tag; it returns an HTML element. The first argument is an object containing attributes, while subsequent arguments represent the children. In essence, these attributes and their values ​​are passed on to the resulting HTML element. However, certain attributes serve specific functions, altering the appearance or behavior of the HTML element.

A simple example is the 'bsSize' attribute: if its value is set to 'sm', the class 'btn-sm' is added to the element.

Most of these specialized attributes can be of the 'van.state' type, allowing you to remotely control the component's appearance within the document. You can try this out for yourself in the demo below.


const { Button, CheckboxInput, Input, RadioSelectInput, SelectInput } = vanB
const { div, h2, span } = van.tags;

var bsSize = van.state('md');
var color = van.state('secondary');
var disabled = van.state(false);
var outline = van.state(false);
var dropdown = van.state(false);
var label = van.state("Button");

function Demo() {

    const OptionsBar = div(
        div({ class: "input-group input-group-sm" },
            span({ class: "input-group-text" }, 'bsSize'),
            RadioSelectInput({
                value: bsSize.val,
                oninput: e => bsSize.val = e.target.value,
                options: 'sm,md,lg', inline: true,
            }),
            span({ class: "input-group-text" }, 'color'),
            SelectInput({
                value: color.val,
                oninput: e => color.val = e.target.value,
                options: ',primary,secondary,success,danger,warning,info,light,dark,link',
            }),
            div({class:  "input-group-text"}, 
                CheckboxInput({ label:'outline', value: outline.val, oninput: e => outline.val = e.target.value }),
            ),
            div({ class: "input-group-text" },
                CheckboxInput({ label: 'disabled', value: disabled.val, oninput: e => disabled.val = e.target.value }),
            ),
            div({ class: "input-group-text" },
                CheckboxInput({ label: 'dropdown', value: dropdown.val, oninput: e => dropdown.val = e.target.value }),
            ),
        ),
    );

    return div({},
        h2('Button Demo'),
        OptionsBar,
        div({ class: "col" },
            Button({ bsSize, color, outline, disabled, dropdown, class: "mt-3" }, label),
        ))
}

FormBuilder

export function FormBuilder ({dom, values, rowClass="", formClass="", cols, autoRow, bsSize, id, onChange}={})

The FormBuilder is arguably the most important feature in this library. It simplifies the creation of forms to the greatest possible extent. The individual steps for using it are:

  1. Create a FormBuilder with function FormBuilder(args)
  2. Start a new row with addRow(class)
  3. Add a form group with label and input control with add(props)
  4. Add the form into dom tree with variable dom
  5. Add a listener for changes with onChange((name,value,event)=>{})
  6. Check form validation with getFormValid() when onvalidate is used in add

Basic Form

const { div, pre } = van.tags;

// create a display for values
const ValueDisplay = pre({class:'mt-2 p-2 bg-body'});

// create a form builder
const fb = vanB.FormBuilder({
    // set initial values
    values: {name:'Jack', email:'jack@black.com'}
})

// add a change event
fb.onChange( () => ValueDisplay.innerHTML = JSON.stringify(fb.values) )

// add a input control
// only 'name' and 'label' are required 
fb.add({label: 'Name', name: 'name'})

// add a second field with 'type'
fb.add({label: 'Email', name: 'email', type: 'email'})

// add element
fb.addChildren( ValueDisplay );

// append the form to demo container
container.appendChild( fb.dom )

// show values in ValueDisplay
fb.emitChange() // display values

Form Validation

Bootstrap offers a few options for form validation feedback. Please read the Bootstrap documentation. For detail information read the Mdn web docs.

Browser Built-In Form Validation

The easiest thing is the browser's own validation, which can of course be used here.

  • required: Specifies whether a form field needs to be filled in before the form can be submitted.
  • minlength and maxlength: Specifies the minimum and maximum length of textual data (strings).
  • min and max: Specifies the minimum and maximum values of numerical input types.
  • type: Specifies whether the data needs to be a number, an email address, or some other specific preset type.
  • pattern: Specifies a regular expression that defines a pattern the entered data needs to follow.

Generally, text is displayed when the mouse is moved over the field. This example uses a pattern for the E-mail and Zip field.

const { Input, FormBuilder } = vanB;
function BrowserValidation() {
    const {div, p, span, small} = van.tags;

    const fb = FormBuilder({formClass: "row g-3"})

Dynamic JavaScript Validation

You can indicate invalid and valid form fields with .is-invalid and .is-valid. For simplicity, the isvalid attribute can be used. Since this can also be a van.state, dynamic validation is possible.

Or even simpler, you pass a function onvalidate then the FormBuilder automatically creates an isvalid attribute. You can then use the FormBuilder function getFormValid to check whether all fields are valid. onvalidate functions takes a value as argument and returns true/false.

The next example uses a better e-mail validation and a complex password validation.

function DynamicValidation() {
    const {div, ul, li} = van.tags;
    const { Button, FormBuilder } = vanB;
    const required = v => !!v;
    const isEmail = v => {
        var re = /^(([^<>()[\]\\.,;:\s@"]+(\.[^<>()[\]\\.,;:\s@"]+)*)|(".+"))@((\[[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\])|(([a-zA-Z\-0-9]+\.)+[a-zA-Z]{2,}))$/;
        return re.test(String(v).toLowerCase());
    }
    const fb = FormBuilder({ rowClass: "mb-2", autoRow: true, cols: "3 6" });
    fb.add({label: "Name", name: "name", type: "text", onvalidate: required});
    fb.add({label: "E-mail", name: "email", type: "text", onvalidate: isEmail}, 
        div({class: "invalid-feedback"}, "Please enter a valid E-mail."), 
        div({class: "valid-feedback"}, "Looks good!")
    );
    fb.add({label: "Password", name: "password", type: "password", 
        onvalidate: v => {
            let regex = /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@.#$!%*?&])[A-Za-z\d@.#$!%*?&]{8,15}$/;
            return regex.test(v)
        }

Custom Input Control

In order to build your own input field, you should consider the following points.

  1. The outer "div" must have the class "form-control". It is ideal to take into account the argument "bsSize" which leads to the classes "form-control-sm" or "form-control-lg".
  2. The "value" argument is used for initialization.
  3. Changes are sent via the "oninput" argument with an "event" as a parameter. Within this library, a fake "event" in the form "{target:{name,value}}" is usually sufficient.
  4. To keep the component dynamic, "van.val()" can be used

This shows how to program an input field to select an alignment. The field should select the string values ​​"left", "right", "center" or "justify". This is followed by a small demonstration form. In the form the field is specified as "input". The specification of “type” can be omitted.

// a custom align control
function AlignInput({value, bsSize, class: clas, style, oninput, color="primary", ...props}) {

    const {div} = van.tags;
    const t = I18n.tPath('align-input');  // title translation

    // create input component
    var divProps = {
        className:  () => {           // merge className
            let res = "d-flex flex-row form-control"; 
            if(van.val(bsSize)) res += ' form-control-' + van.val(bsSize);
            if(van.val(clas)) res += ' ' + van.val(clas);
            return res;
        },
        style: () => {                   // merge style
            let res = "max-width: max-content";
            if(van.val(style)) res += '; ' + van.val(style);
            return res;
        },
        value: van.val(value),
        role: 'group', 
        ...props
    };
    const component = div({...divProps})

    // make the buttons
    const buttonProps = [ // define button props
        {name: 'align left', value: 'left'},
        {name: 'align right', value: 'right'},
        {name: 'align center', value: 'center'},
        {name: 'align justify', value: 'justify'},
    ];
    const setSelect = newValue => {
        const buttons = div(
            ...buttonProps.map( param => vanB.Button({
                bsSize,
                class: "py-1 px-2 me-1",
                onclick: () => {
                    // send new value per mockup event
                    oninput({ target: { name: props.name, value: param.value }});
                    // repaint buttons
                    setSelect(param.value);  
                },
                color,
                outline: newValue !== param.value,
                title:  t(param.name)
            }, vanB.Icon(param.name) ))
        )
        component.replaceChildren( buttons )  
    };

    // set initial value
    if(typeof value !== 'string' || !buttonProps.find( item => item.name === value) ) value = 'left'; // default
    setSelect(value); // put buttons into component

    return component
}

SelectOptions

function selectOptions (list, dom=false, selected)

The form controls in this library use the selectOptions function. It converts different kind of lists into a uniform format {value, children} that can easily be mapped into a DOM as <option> elments. Is the parameter "dom" "true", the function returns a ready mapped dom option list.

The "list" parameter accepts four notations:

  1. 'TextValue1,TextValue2'
    a komma separated list
  2. ['TextValue1', 'TextValue2'...]
    a array of values
  3. [['Text1', Value1], ['Text2', Value2]...]
    a array of display / value pairs
  4. [ { value: 1, ['children' || 'text' || 'displayValue'] }
    a array of objects

Notations can be mixed inside a array.

For example [ '', ['text 1', 1], ['text 2', 2] ] will be converted to:

[
  {
    value: '',
    children: '',
  },
  {
    value: 1,
    children: 'text 1',
  },
  {
    value: 2,
    children: 'text 2',
  }
]

and with dom=true and selected: "1":

[
 option({value=""}),
 option({value="1", selected: true}, "text 1"),
 option({value="2"}, "text 2"),
]

function ToggleTheme() {

      onclick: toggleClick,
      title:   "toggle theme",
    });
}

export function dragSort (list, setList)

  • setList: function to store reordered list

Function DragSort returns an object with all required function. The function dragProps of the object can inject all html attributes like draggable, ondragstart and so on.

The function used to be a React Hook, but works great in VanJs and is now used in this library by TagInput.

During dragging CSS :dragging is set.

            class: () => "list-group-item",
            ...drag.dragProps(index)                // inject properties
            },

        )
    });
