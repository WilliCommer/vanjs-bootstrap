(static) FormBuilder(paramsopt) → {object}

Description:

  • function FormBuilder({dom, values, rowClass="", formClass="", cols, autoRow, bsSize, id, onChange}={})

    A FormController with convenient features for creating forms quickly. It creates rows, adds form groups, keeps the DOM tree, manages validation, and updates values from input events.

Source:
  • form-controls.js, line 608
Properties:
Name Type Description
dom HTMLElement

form DOM container
values object

current values from the controller
rowClass string

default CSS class for rows
formClass string

CSS class applied to the form element
cols string

default columns setting for inputs
autoRow boolean

automatically create rows when columns exceed 12
bsSize string

default Bootstrap size for children controls
id string

form id prefix used for generated input ids
onChange(func) function

subscribe to changed values
add(args) function

add a form group to the current or new row. add(args, ...children)
addGroup(args) function

add a prepared form group directly. addGroup(args, ...children)
addRow(arg) function

create a new row or end the current one with null
addChildren(...children) function

add HTMLElements to dom
getFormValid() function

return true if all validation checks pass
setValues(values) function

update a set of field values in the form
groupIdByName(name) function

return generated group id
inputIdByName(name) function

return generated control id
labelIdByName(name) function

return generated label id
Example
const fb = FormBuilder({
  formClass: 'row g-2 m-2 p-2',
  autoRow: true,
});
fb.add({ name: 'name', label: 'Name', type: 'text' });
fb.add({ name: 'pw', label: 'Password', type: 'password' });

class for the generated rows if autoRow is true
