vanjs-bootstrap/i18n

function I18n()

Create a translation manager for localized strings. The returned object keeps a dictionary by language, resolves nested keys, and can add or merge new translations.

Description:

    Create a translation manager for localized strings. The returned object keeps a dictionary by language, resolves nested keys, and can add or merge new translations.

Example
import i18n from 'vanjs-bootstrap/i18n; // import extra module
const I18n = i18n(); // create instance
I18n.addWords({ hello: 'Hello' }, 'en');
I18n.addWords({ hello: 'Hola' }, 'es');
I18n.addWords({ hello: '你好' }, 'zh');
I18n.addWords({ hello: 'Hallo' }, 'de');

I18n.setLanguage('de');
console.log(I18n.t('hello')); // -> Hallo
