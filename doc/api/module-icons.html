(static) Icon(icon, props)

Description:

  • Icon( anything, {size, ...props} )

    Create a HTMLElement to display a small (1em by default) image. The value of 'size' is a 'style' value and applies to 'width' and 'height', for example '16px', '2.5em', '60%' or 'inherit'.

    First argument is

    • a key to an image registered with setIcon like 'MOON'
    • a UTF-8 char like '🌙'
    • a SVG string
    • a object with property 'src' to a image url and optional props 'alt', 'size', class...
    • a HTMLElement
    • a function like props=>Icon('MOON', props)
    • a Font Awesome class like 'fa-solid fa-house'
