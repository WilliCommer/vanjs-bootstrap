tag-input

function TagInput({...})

A form multi-select control for editing a list of tag values. It supports drag sorting, option selection, inline creation of new tags, keyboard interaction, and custom icons/translations.

Example
import TagInput from 'vanjs-bootstrap/tag-input';

const values = van.state('red,blue');
const input = TagInput({
  value: values.val,
  options: 'red,green,blue',
  oninput: e => values.val = e.target.value,
});
